# ChaptersCraft AI 📚✨

ChaptersCraft AI is an advanced scholarly and manuscript editing studio equipped with deep research synthesis, Anti-AI humanizing pipelines (StealthHumanizer, CleverHumanizer, QuillBot standards), Turnitin < 2% AI evasion, cross-source plagiarism detection, and Supabase cloud persistence.

## 🚀 Features

- **Turnitin AI Risk Inspector**: Real-time sentence-by-sentence detection with 4 global-standard academic rephrase modes.
- **StealthHumanizer Multi-Layer Suite**: Ninja bypass mode with 12-metric authenticity radar.
- **Plagiarism & Similarity Scanner**: Cross-references academic corpus and Vault files with 1-click citation injection.
- **Duplicate Idea & Paragraph Redundancy Detector**: Identifies and removes repeated premises.
- **Supabase Cloud Sync**: Instant backup across `CC_projects`, `CC_chapters`, `CC_references`, and `CC_correction_history`.
- **Cloudflare Ready**: Native SPA routing and static asset delivery.

## 🛠️ Tech Stack

- React 19 + TypeScript + Vite
- Cloudflare Workers / Pages
- Supabase Database (`CC_` tables)
- PDF.js & Mammoth (Full text extraction)

## 📦 Deployment

```bash
npm install
npm run build
npm run deploy
```
